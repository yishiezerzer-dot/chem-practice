# Chemistry review log

Purpose: Yishi's working log for reviewing the chemistry content (questions and readings) of the HUJI General Chemistry flashcard site, before any content is changed.

How to use:
- Only Yishi marks an item `fixed`. Status values are `open` or `fixed`; everything here starts as `open`.
- This log changes no data. It lists what to check; it does not say any value is right or wrong. Fixes are separate, later changes.
- Item ids: questions use their id from `data/questions.json` (for example `t9-q3`). Readings have no item ids of their own, so a reading is written as `reading:<topic id>` (the topic id from `data/topics.json`), and a section inside it is cited by its section id from `data/readings.json` (for example `hess-formation`).
- Values are quoted exactly as written in the content files (including `<sub>`/`<sup>` markup in readings).
